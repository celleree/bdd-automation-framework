# BDD Automation Framework

A small Java 21 BDD test automation framework built with Maven, Cucumber-JVM, Selenium WebDriver, RestAssured, and TestNG.

## Prerequisites

- Java 21
- Maven 3.9+
- Git
- Google Chrome

## Build

From the repository root, run:

```powershell
mvn test
```

Phase 2 establishes the Maven project skeleton and dependency setup. Test scenarios and framework implementation are added in later phases.
